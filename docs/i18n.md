# 언어 규칙

## 지원 언어

| 코드 | 언어 | 사전 |
| --- | --- | --- |
| `ko` | 한국어 | `src/locales/ko.js` |
| `en` | English | `src/locales/en.js` |
| `ja` | 日本語 | `src/locales/ja.js` |
| `zh-Hans` | 简体中文 | `src/locales/zh-Hans.js` |
| `zh-Hant` | 繁體中文 | `src/locales/zh-Hant.js` |

## 언어 고르기

`src/i18n.svelte.js`의 `pickLocale`이 정한다.

1. 사용자가 고른 언어가 `localStorage`의 `vrc-video-rotate.locale`에 있으면 그것을 쓴다.
2. 없으면 `navigator.languages`를 앞에서부터 보고 처음 맞는 언어를 쓴다.
   - `zh-Hant*`, `zh-TW`, `zh-HK`, `zh-MO`는 `zh-Hant`, 나머지 `zh*`는 `zh-Hans`다.
   - `ko*`, `ja*`, `en*`는 같은 언어다.
3. 맞는 것이 없으면 `en`이다.

- 위 바의 언어 선택으로 바꾸면 바로 다시 그려지고, 고른 값을 저장한다. 저장소를 쓸 수 없으면 조용히 넘어간다.
- 언어가 바뀌면 `<html lang>`과 `document.title`도 바꾼다. 글꼴은 `lang`을 따라 바뀐다([design.md](design.md#글꼴)).
- `index.html`의 기본값은 `lang="en"`과 영어 제목이다. 스크립트가 실행되면 고른 언어로 바뀐다.

## 사전

- `ko.js`가 기준 사전이다. 키를 더하거나 뺄 때는 다섯 사전을 함께 고친다. `src/i18n.test.js`가 모든 사전의 키가 `ko`와 같은지 검사한다.
- 키 이름은 영어 camelCase다. 값이 여러 갈래인 키는 `rotation_90`처럼 밑줄 뒤에 갈래 값을 붙인다.
- 자리표시자는 `{name}` 형식이고, `t('loadFailed', { name })`처럼 넘긴다. 어순은 언어마다 자리표시자 위치로 맞춘다.
- 사전에는 문구만 둔다. HTML, 색, 숫자 서식을 넣지 않는다.

## 화면 문구

- 사용자에게 보이는 글자는 모두 `t(key)`로 넣는다. 템플릿, `aria-label`, `title`, 오류 문구가 모두 해당한다.
- 예외는 파일 이름과 각도 숫자처럼 사용자 데이터이거나 언어와 무관한 값이다.
- `src/lib/`의 코드는 언어를 모른다. 던지는 `Error`의 메시지는 개발자용 영어이고 화면에 그대로 보이지 않는다. 화면은 실패를 `loadFailed` 문구로 바꿔 보여 준다.
- 용어는 [GLOSSARY.md](../GLOSSARY.md)를 따른다.

## 문체

| 언어 | 문체 |
| --- | --- |
| `ko` | 설명은 합니다체, 사용자에게 권하는 말은 "-하세요". 버튼은 "영상 열기", "저장"처럼 명사형 |
| `en` | 문장형 대문자(첫 글자만 대문자). 버튼은 "Open video"처럼 동사로 시작 |
| `ja` | です・ます体. 버튼은 "動画を開く"처럼 동사형 |
| `zh-Hans` | 간체자, 중국 대륙 용어(视频, 文件) |
| `zh-Hant` | 번체자, 대만 용어(影片, 檔案, 儲存) |

- 숫자와 단위 사이: CJK 문장 안의 라틴 문자·숫자 앞뒤에는 공백을 둔다(`時計回りに 90°`). 단 `°`는 숫자에 붙인다.
- 한국어·일본어의 나열 가운뎃점은 `·`(ko), `・`(ja)을 쓴다.

## 언어 더하기

1. `src/locales/<코드>.js`에 `ko.js`와 같은 키로 사전을 만든다.
2. `src/i18n.svelte.js`의 `DICTIONARIES`에 넣고, 필요하면 `pickLocale`의 대응 규칙을 고친다.
3. `src/app.css`에 `:root:lang(<코드>)` 글꼴 목록을 더하고 [design.md](design.md#글꼴) 표를 고친다.
4. 이 문서의 표와 [GLOSSARY.md](../GLOSSARY.md)의 번역 표를 고친다.
5. `pnpm run test`로 키가 맞는지 확인한다.
