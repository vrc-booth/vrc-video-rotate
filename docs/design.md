# 디자인 규칙

## 원칙

- 기준은 vrc-print-cropper의 "암실" 시안이다. 어두운 바탕 위에서 영상만 밝게 보이고, 나머지 화면은 영상보다 눈에 덜 띈다.
- 영상이 주인공이다. 강조색은 저장 버튼에만 쓴다.
- 한 화면에 미리보기, 회전, 저장이 함께 보인다. 모달과 숨은 메뉴를 쓰지 않는다.
- 장식을 넣지 않는다. 그라데이션, 일러스트, 애니메이션 효과가 없다.
- 화면 문구는 [GLOSSARY.md](../GLOSSARY.md)의 용어를 쓰고, [i18n.md](i18n.md)에 따라 언어 사전에서 가져온다.

## 색

`src/app.css`의 `:root`에 CSS 변수로 정의한다. 화면 코드에서 색 값을 직접 쓰지 않는다. 테마는 어두운 테마 하나만 두고, `index.html`에 `<meta name="color-scheme" content="dark">`를 둔다.

| 변수 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `--bg` | `#17181A` | 페이지 바탕 |
| `--panel` | `#1F2023` | 보조 버튼, 선택 상자 |
| `--stage` | `#0F1012` | 미리보기 뒤 무대 |
| `--line` | `#2A2C30` | 영역 경계선 |
| `--line-strong` | `#3A3C41` | 버튼, 입력 테두리 |
| `--text` | `#E8E8E6` | 본문 |
| `--muted` | `#A6A8AD` | 보조 문구, 회전 상태, 라벨 |
| `--accent` | `#4C9EFF` | 저장 버튼, 끌어다 놓는 동안의 무대 테두리 |
| `--accent-text` | `#0B1220` | 강조색 위 글자 |
| `--focus` | `#7DB8FF` | 키보드 포커스 테두리 |
| `--danger` | `#FF7A7A` | 열기 실패 문구 |

- 글자와 바탕의 명암비는 본문 4.5:1, 큰 글자와 아이콘 3:1 이상을 지킨다. 새 색을 더할 때 이 기준을 확인한다.
- 영상 미리보기에는 그림자 `0 8px 32px rgba(0,0,0,0.5)`만 준다. 테두리를 두르지 않는다.

## 글꼴

웹 글꼴을 쓰지 않고 시스템 글꼴을 쓴다. 한국어 웹 글꼴로 일본어와 중국어를 표시하면 한자 모양이 어긋나기 때문이다. `<html lang>`에 따라 `:root:lang()` 규칙으로 글꼴 목록을 바꾼다.

| 언어 | 글꼴 목록 |
| --- | --- |
| 기본, `en` | `system-ui, -apple-system, "Segoe UI", sans-serif` |
| `ko` | `"Apple SD Gothic Neo", "Malgun Gothic", system-ui, sans-serif` |
| `ja` | `"Hiragino Sans", "Yu Gothic UI", "Meiryo", system-ui, sans-serif` |
| `zh-Hans` | `"PingFang SC", "Microsoft YaHei", system-ui, sans-serif` |
| `zh-Hant` | `"PingFang TC", "Microsoft JhengHei", system-ui, sans-serif` |

| 쓰임 | 크기 | 굵기 |
| --- | --- | --- |
| 앱 제목 | 16px | 700 |
| 본문, 버튼 | 14px | 400 |
| 저장 버튼 | 15px | 700 |
| 파일 이름, 언어 라벨, 안내 | 13px | 400 |
| 회전 상태, 바닥글 | 12px | 400 |

- 대문자 변환과 글자 사이 넓히기를 문구에 쓰지 않는다. CJK 문구에서 어색해진다.

## 간격과 모양

- 간격은 4, 8, 12, 16, 20, 24px만 쓴다.
- 모서리는 선택 상자 6px, 버튼과 무대 8px이다.
- 영역은 바탕색 차이와 1px `--line` 경계선으로 나눈다. 카드 그림자를 쓰지 않는다.

## 배치

| 위치 | 내용 |
| --- | --- |
| 위 바 | 왼쪽에 앱 제목, 오른쪽에 영상 열기와 언어 선택 |
| 무대 | 남은 높이 전부. 영상을 비율대로 무대 안에 맞춘다 |
| 도구 줄 | 무대 바로 아래. 왼쪽에 파일 이름과 회전 상태, 오른쪽에 왼쪽 회전, 오른쪽 회전, 저장 |
| 상태 줄 | 열기 실패 문구. 비어 있으면 높이가 없다 |
| 아래 바 | 개인 정보 안내 |

- 페이지는 창 높이에 맞고(`body { height: 100vh }`), 무대가 남은 공간을 채운다. 무대의 최소 높이는 화면 높이의 56%와 폭의 80% 중 작은 값이다.
- 아무것도 열지 않았거나 열기에 실패하면 무대 전체가 "영상 열기" 버튼이자 끌어다 놓는 자리다. 도구 줄은 영상이 열렸을 때만 보인다.
- 바와 도구 줄은 `flex-wrap`으로 줄을 바꾼다. 휴대폰 너비에서 가로 스크롤이 생기지 않고, 양옆 여백은 16px 이상이다.
- 미디어 쿼리는 `prefers-reduced-motion` 외에 쓰지 않는다.

## 구성 요소

### 버튼

| 종류 | 모양 | 쓰는 곳 |
| --- | --- | --- |
| 주 버튼 | `--accent` 바탕, `--accent-text` 글자, 테두리 없음 | 저장 하나뿐 |
| 보조 버튼 | 투명 바탕, `--line-strong` 테두리 | 영상 열기 |
| 아이콘 버튼 | `--panel` 바탕, `--line-strong` 테두리, 20px 아이콘, 글자 없음 | 왼쪽 회전, 오른쪽 회전 |
| 빈 무대 버튼 | 무대를 채우는 투명 바탕, 점선 `--line-strong` 테두리 | 아무것도 열지 않았을 때의 영상 열기와 끌어다 놓기 안내 |

- 누를 수 있는 것은 모두 가로세로 44px 이상이다.
- 아이콘 버튼에는 `aria-label`과 `title`을 둔다. 문구는 언어 사전에서 가져온다.
- 저장은 내려받기 링크(`<a download>`)를 주 버튼 모양으로 꾸민다.

### 회전

- 회전 버튼은 누를 때마다 90°씩 상대적으로 돌린다. 영상을 새로 열면 원래 방향(0°)에서 시작한다.
- 현재 회전 상태는 파일 이름 옆에 `--muted`로 표시한다. 원래 방향, 시계 방향 90°, 180°, 반시계 방향 90° 네 가지다.
- 저장 파일 이름은 원래 이름 뒤에 `_rot{각도}`를 붙인다. 예: `clip_rot90.mp4`.

### 아이콘

- `src/Icon.svelte`에 둔다. 24 단위 viewBox의 인라인 SVG이고, 선 굵기 2, 둥근 끝, `currentColor`를 쓴다.
- 아이콘 SVG에는 `aria-hidden="true"`를 둔다. 이름은 버튼이 가진다.

### 상태 문구

- 열기 실패는 `.status`(`aria-live="polite"`)에 `--danger` 색으로 파일 이름과 함께 표시한다.
- 성공은 따로 알리지 않는다. 미리보기가 바뀌는 것으로 충분하다.

## 상호 작용

- 키보드 포커스는 `:focus-visible`에서 2px `--focus` 테두리, 2px 간격으로 표시한다. 포커스 표시를 지우지 않는다.
- 끌어다 놓는 동안 무대에 2px `--accent` 테두리를 두른다. 창 어디에 놓아도 첫 파일을 연다.
- 전환 효과는 색과 테두리에만 120ms 이내로 쓴다. `prefers-reduced-motion: reduce`이면 쓰지 않는다.
- 커서는 누를 수 있는 것에만 `pointer`이다.
